## Classification rule

- **Sourced:** copied or derived from a registered real source.
- **Measured:** produced by a documented Geo-Sentry experiment.
- **Estimate:** reasoned approximation; never present as fact.
- **Assumption:** design input awaiting validation.
- **Synthetic:** generated data used only for software or workflow testing.
